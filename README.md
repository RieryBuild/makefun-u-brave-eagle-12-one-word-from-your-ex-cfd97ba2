One word my ex would use to describe me, entered in the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun.

The word is **convenient** — not loved, just easy to keep around: chosen because I was handy, never because I was wanted. It is the funniest, most painfully honest single word for the role: a whole failed relationship, kept for ease instead of desire, in ten letters.

## Run it

```sh
python3 main.py
```

This writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Standard library only.
